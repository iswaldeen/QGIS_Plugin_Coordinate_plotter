 - Refreshed dialog layout for improved clarity and visual appearance.
 - Increased dialog height to better accommodate all controls.
 - Added support for pasting complete coordinate pairs directly into a single input field.
 - Added automatic coordinate parsing from common sources such as QGIS and Google Maps.
 - Coordinate labels now update dynamically based on the selected CRS.
 - Geographic CRS inputs are displayed as Longitude/Latitude.
 - Projected CRS inputs are displayed as Easting/Northing with CRS units.
 - Improved coordinate entry guidance and input validation.
