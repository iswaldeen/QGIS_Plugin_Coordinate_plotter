Coordinate Plotter Help

What does this tool do?

Coordinate Plotter creates a point on the QGIS map from entered or pasted coordinates. Coordinates can be typed manually or pasted as a complete coordinate pair copied from sources such as QGIS or Google Maps.

How to use the tool

  1. Open Coordinate Plotter from the QGIS toolbar or plugin menu.
  2. Choose whether to add the point to an existing layer or create a temporary layer.
  3. Enter the coordinates manually, or paste a complete coordinate pair into the paste coordinate box.
  4. Check that the coordinate labels match the CRS you are using.
  5. Click OK.
When the tool opens, no plotting option is selected. Choose one option before entering coordinates.

Pasting a complete coordinate

The dialog includes a paste coordinate box for entering a full coordinate pair in one step. This is useful when copying coordinates directly from QGIS, Google Maps, spreadsheets, reports, or other documents.

Paste the full coordinate into the box, then click OK. The plugin reads the two numeric values and copies them into the main coordinate fields before plotting the point.

Accepted coordinate formats

  • 530000, 180000
  • 530000 180000
  • 530000; 180000
  • 51.5074, -0.1278
  • -0.1278, 51.5074
The pasted coordinate should contain exactly two numeric values. Extra text is ignored where possible, but the tool will warn you if it cannot identify a valid coordinate pair.

CRS-aware coordinate labels

Coordinate Plotter updates the coordinate labels based on the CRS currently being used. This helps make it clearer whether the expected values are longitude/latitude or projected X/Y coordinates.

  • For a geographic CRS, the fields are shown as Longitude / X and Latitude / Y.
  • For a projected CRS, the fields are shown as Easting / X and Northing / Y, using the CRS map units where available.
QGIS stores point coordinates as X and Y. For geographic coordinate systems, X means longitude and Y means latitude.

Google Maps coordinates

Google Maps commonly copies coordinates as latitude, longitude. When a geographic CRS is selected, the plugin attempts to detect this format and place the values into the correct QGIS X/Y fields.

Always check that the selected CRS matches the coordinates you are plotting. A valid coordinate pair can still appear in the wrong place if it is plotted using the wrong CRS.

Plotting options

Use an existing point layer

  • Select Choose an existing map layer.
  • Choose a point layer from the dropdown.
  • Enter the coordinates manually or paste a complete coordinate pair.
  • Click OK.
Only point layers can be selected. If no valid point layer is available, the OK button will stay disabled.
Existing layers use their own CRS. Make sure your coordinates match the CRS of the selected layer.

Create a temporary layer

  • Select Create a temporary layer.
  • Choose whether to use the project CRS or select another CRS.
  • Enter the coordinates manually or paste a complete coordinate pair.
  • Click OK.
Temporary layers are not saved automatically. To keep the point, right-click the layer and choose Export > Save Features As....

CRS options

When creating a temporary layer, Use project CRS is selected by default. Untick it if you want to choose a different CRS.

The CRS selector is only available when creating a temporary layer. It is disabled when plotting to an existing layer.
Make sure your coordinates match the CRS you are using. For example, British National Grid coordinates should be used with EPSG:27700.

After plotting

After the point is created, QGIS zooms to the new point and shows a confirmation message.

If the selected layer was already in edit mode, the new point is added to the edit session. Save the layer edits in QGIS to keep the point permanently.

Updated dialog layout

The dialog layout has been refreshed to improve clarity and make the coordinate, CRS, and plotting options easier to follow. The dialog height has also been increased so that all controls fit more comfortably.

Help button and display

The help button uses a light or dark icon depending on your current QGIS theme, so it remains visible in both light and dark mode.

Common issues

  • The OK button is disabled: select a plotting option and, if using an existing layer, choose a valid point layer.
  • The point appears in the wrong place: check that the coordinates match the CRS being used.
  • No layers appear in the dropdown: make sure your project contains at least one point layer.
  • The CRS option is disabled: this is normal when using an existing layer.
  • The pasted coordinate is not accepted: make sure it contains exactly two numeric values.
  • Longitude and latitude look reversed: check whether the source copied the coordinate as latitude, longitude.
