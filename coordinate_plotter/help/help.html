Coordinate Plotter Help

What does this tool do?

Coordinate Plotter allows you to create a point on the QGIS map by typing in an X coordinate and a Y coordinate.

How to use the tool

  1. Open the Coordinate Plotter tool from the QGIS toolbar or plugin menu.
  2. Choose where the new point should be added.
  3. Enter the X and Y coordinates.
  4. Click OK.
When the tool first opens, no plotting option is selected. This is intentional, so you can choose whether to add the point to an existing layer or create a temporary layer.

Option 1: Choose an existing map layer

  • Select Choose an existing map layer.
  • Choose a point layer from the layer dropdown.
  • Enter the X and Y coordinates.
  • Click OK.
Only point layers can be selected. If no valid point layer is available, the OK button will stay disabled.
When using an existing map layer, the CRS option is disabled. The point will be added using the CRS of the selected layer.

Option 2: Create a temporary layer

  • Select Create a temporary layer.
  • Enter the X and Y coordinates.
  • Choose whether to use the project CRS or select another CRS.
  • Click OK.

Using the CRS options

By default, Use project CRS is checked when creating a temporary layer. This means the new temporary layer will use the same coordinate reference system as the current QGIS project.

To choose a different CRS for a temporary layer:

  1. Select Create a temporary layer.
  2. Untick Use project CRS.
  3. Use the CRS selector to choose the coordinate system you want.
  4. Enter your coordinates.
  5. Click OK.
The CRS selector only applies when creating a temporary layer. Existing layers already have their own CRS.
Make sure your X and Y coordinates match the CRS you are using. For example, British National Grid coordinates should be used with EPSG:27700.

After plotting

Once the point is created, QGIS will zoom to the plotted coordinate and show a confirmation message.

Common issues

  • The OK button is disabled: select a plotting option and make sure a valid point layer is selected if using an existing layer.
  • The point appears in the wrong place: check that the coordinates match the CRS being used.
  • No layers appear in the dropdown: make sure your project contains at least one point layer.
  • The CRS option is disabled: this is normal when using an existing map layer.

Temporary layers

Temporary layers are not automatically saved to disk. To keep the plotted point permanently, right-click the layer in QGIS and choose Export > Save Features As....
